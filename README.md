# 만보기 프로젝트

## 프로젝트 개요

블루투스로 목표 걸음수를 입력하면, 가속도 센서를 이용해 **Z축 가속도 값**을 측정하고 이를 기반으로 걸음수를 계산하는 만보기 시스템입니다.

현재 걸음수는 **Dot Matrix**를 통해 실시간으로 표시되며, 목표 걸음수를 달성하거나 중도 포기할 경우 최종 결과가 블루투스를 통해 출력됩니다.

출력되는 결과는 다음과 같습니다.

- 걸음수
- 이동 거리
- 측정 시간
- 평균 속도

---

## 주요 기능

### 1. 블루투스를 통한 목표 걸음수 입력

사용자는 블루투스 통신을 통해 목표 걸음수를 입력할 수 있습니다.  
입력된 목표값은 만보기 동작의 기준값으로 사용됩니다.

---

### 2. 가속도 센서를 이용한 걸음수 측정

가속도 센서를 통해 **Z축 가속도 값**을 측정합니다.  
측정된 Z값은 `step_counter IP`로 전달되어 걸음수와 이동 거리를 계산하는 데 사용됩니다.

- 가속도 센서로 Z축 값 측정
- `step_counter IP`에서 걸음수 계산
- 보폭 기준으로 이동 거리 계산
- 현재 걸음수는 Dot Matrix에 출력

---

### 3. 목표 달성 및 중도 포기 처리

목표 걸음수를 달성하면 측정을 종료하고 Dot Matrix 출력도 정지합니다.  
또한 사용자가 중도 포기를 선택할 경우, 현재까지 측정된 값을 기준으로 결과를 출력합니다.

---

### 4. 블루투스를 통한 결과 출력

측정 종료 후 블루투스를 통해 최종 결과를 출력합니다.

출력 항목은 다음과 같습니다.

| 항목 | 설명 |
|---|---|
| 걸음수 | 측정된 총 걸음 수 |
| 이동 거리 | 걸음수를 기반으로 계산한 거리 |
| 측정 시간 | 측정 시작부터 종료까지의 시간 |
| 평균 속도 | 이동 거리와 측정 시간을 기반으로 계산한 속도 |

---

## 시스템 동작 흐름

```text
블루투스로 목표 걸음수 입력
        ↓
가속도 센서로 Z축 값 측정
        ↓
step_counter IP에서 걸음수 및 거리 계산
        ↓
현재 걸음수를 Dot Matrix에 표시
        ↓
목표 달성 또는 중도 포기
        ↓
블루투스로 걸음수, 거리, 시간, 속도 출력

| 모듈                   | 역할                |
| -------------------- | ----------------- |
| Bluetooth            | 목표 걸음수 입력 및 결과 출력 |
| Accelerometer Sensor | Z축 가속도 값 측정       |
| step_counter IP      | 걸음수 및 이동 거리 계산    |
| Dot Matrix           | 현재 걸음수 표시         |
